# Rats Reborn — документация проекта

## Цель

Порт и развитие мода **Rats** (AlexModGuy) с версии Minecraft **1.20.1** на **1.21.1** с доработкой механик.

## Исходный код (официальный)

| Параметр | Значение |
|----------|----------|
| Репозиторий | https://github.com/AlexModGuy/Rats |
| Лицензия | LGPL-3.0 |
| Загрузчик | NeoForge |
| Зависимость | Citadel (обязательна для 1.14.4+) |

### Ветки на GitHub

| Ветка | Назначение |
|-------|------------|
| `1.20` | **Актуальная** — последний коммит 2024-11-15, версия мода **8.1.3**, Minecraft **1.20.1** |
| `1.19` | Старая линейка 1.19.x |
| `1.16` … `1.14.4` | Устаревшие порты |
| `master` | Не является рабочей веткой разработки (устарела) |

Ветки **1.21** / **1.21.1** в официальном репозитории **нет**. Релизов на Modrinth/CurseForge для 1.21.1 также нет (по состоянию на май 2026).

### Последний релиз на CurseForge

- **Rats 8.1.3** для **1.20.1** (NeoForge), дата: 15 ноября 2024.

## Локальная копия в проекте

| Путь | Описание |
|------|----------|
| `Rats-1.20/` | Распакованные исходники ветки `1.20` |
| `Rats-1.20-source.zip` | Архив с GitHub (для повторной распаковки) |

Параметры сборки из `Rats-1.20/gradle.properties`:

- `mod_version=8.1.3`
- `minecraft_version=1.20.1`
- `neo_version=47.1.64`

## Не путать с другим модом

**Rat's Mischief** (Ladysnake, Fabric) — отдельный проект: https://github.com/Ladysnake/RATs-Mischief. К официальному Rats (AlexModGuy) не относится.
