# Система крыс

Центральная механика мода. Почти вся автоматизация строится вокруг приручённой крысы (`TamedRat`).

## Иерархия классов

```
TamableAnimal (ваниль)
└── AbstractRat          — анимация Citadel, варианты, сон, сидение, базовый ИИ
    ├── DemonRat         — враждебный демон Нижнего мира
    └── DiggingRat       — копание, рейд сундуков и урожая (дикие)
        ├── Rat          — дикая крыса
        └── InventoryRat — инвентарь, команды, радиус, патруль
            └── TamedRat — приручённая: улучшения, RF, танцы, рабочие цели
```

| Класс | Файл | Роль |
|-------|------|------|
| `AbstractRat` | `server/entity/rat/AbstractRat.java` | Общее поведение, пол `IS_MALE`, сон `SLEEPING`, вариант `COLOR_VARIANT` |
| `DiggingRat` | `DiggingRat.java` | `RatRaidChestsGoal`, `RatRaidCropsGoal` |
| `Rat` | `Rat.java` | Чума `PLAGUE`, доверие `wildTrust`, дом в NBT |
| `InventoryRat` | `InventoryRat.java` | `RatCommand`, `RatContainer`, точки патруля |
| `TamedRat` | `TamedRat.java` | Улучшения, harvest/deposit/pickup, посохи, ~1470 строк |

Отдельная ветка: `DemonRat` — не наследует `InventoryRat`.

## Синхронизируемые данные (примеры)

**AbstractRat:** сидит, спит, вариант окраски, застряла в ловушке.

**Rat (дикая):** чума, тога, превращение в короля крыс.

**InventoryRat:** команда, центр радиуса, дом, узлы патруля, флаги видимости улучшений.

**TamedRat:** тога, окраска, танец, запас RF, точки забора/склада (`PICKUP_POS`, `DEPOSIT_POS`).

Рабочие цели приручённой крысы используют сглаженную установку пути: одинаковая цель не пересоздаётся каждый тик, поэтому движение при работе выглядит плавнее. Для крыс с карьерным улучшением оставлена прямая карьерная навигация, чтобы точные шаги шахты не ломались.

Для больших поселений цели крыс разнесены по времени: после загрузки мира сотни крыс не запускают тяжёлые поиски в один тик. Поиск сыра на 128 блоков оставлен, но проверка пути выполняется только для ближайших кандидатов, а пустой поиск получает более длинную паузу. Рабочие сканы урожая, посадки, рыбалки, стрижки, бутылочника и садовника ищут ближайший блок без промежуточного списка всех подходящих позиций. Create-работяга больше не пересчитывает путь в каждой проверке продолжения цели: путь строится при выборе цели, а дальше проверяется только валидность блока и расстояние. Если крыса ждёт подходящий предмет на ленте Create, она делает короткую паузу между проверками, чтобы не нагружать сервер reflection-доступом к ленте и рецептам каждый тик.

Следующий слой оптимизаций уменьшает стоимость постоянного тика: Create-рецепты и найденные поля ленты кешируются до перезагрузки менеджера рецептов, совпадение пары «предмет крысы + предмет на ленте» запоминается и не заставляет каждую крысу снова перебирать все рецепты. У приручённой крысы кешируются частые признаки улучшений работника, карьера и полёта, поэтому движение и проверки целей не разбирают слоты улучшений каждый тик. Голод проверяется раз в секунду с разносом по сущностям, забор предметов получил короткую задержку старта, а цели возврата в домик и удержания рядом с рабочей точкой больше не опрашиваются всеми крысами синхронно каждый тик. Пакеты переносимой жидкости отправляются только игрокам, которые отслеживают конкретную крысу.

Третий проход оптимизаций закрывает самые частые проверки транспорта: сдача предметов получила такую же задержку старта, как забор, поэтому крыса с предметом в лапах не опрашивает склад каждый тик. Для улучшения «блюдо» результат поиска одинаковых предметов рядом кешируется на короткое время и не строит пути к предметам на каждом тике движения к складу. Доступ к инвентарям больше не создаёт новый порядок сторон при каждом обращении, а Create-совместимость кеширует методы, классы, пригодность предметов применения и методы `Item Drain`. Суточная сытость крыс кешируется на сервере на одну секунду, а harvest-цели кешируют проверку подбираемых предметов между запусками.

Шумное диагностическое логирование переведено в скрытый отладочный уровень: сохранение слотов крыс, обычные отказы Create Item Drain принять жидкость, сброс зависшего трубного перехода, отсутствие стола зачарования и ряд штатных отказов Create-работяги больше не засоряют `latest.log`. Ошибки исполнения остаются на уровне `error`, чтобы реальные поломки не терялись.

## Цели искусственного интеллекта

### AbstractRat
- Плавание, избегание кошек/лис
- `RatFleePositionGoal`, `MeleeAttackGoal`, блуждание, взгляд на игрока
- `HurtByTargetGoal`, защита владельца

### DiggingRat
- Рейд сундуков и урожая (настраивается конфигом `ratsStealItems`, `ratsBreakCrops`)

### Rat (дикая)
- Избегание игрока, паника, поиск еды
- Вход в ловушку, защита чумного доктора
- Атака игроков с эффектом чумы

### TamedRat (дополнительно)
- `RatFollowOwnerGoal`, `RatStayCloseToHomeGoal`
- `RatHarvestCropsGoal`, `RatFarmGoal`, `RatFishermanGoal`, `RatQuarryGoal`, …
- `RatPickupGoal`, `RatDepositGoal`
- `RatPatrolGoal`, `RatTargetItemsGoal`
- `SitWhenOrderedToGoal`

Полный список harvest-целей — в `server/entity/ai/goal/harvest/`.

## Улучшения на крысе

- До **3 слотов** улучшений в GUI (`RatUpgradeMenu`).
- Проверка: `RatUpgradeUtils.hasUpgrade(rat, item)`.
- Улучшения меняют ИИ через `ChangesAIUpgrade`, каждый тик — `TickRatUpgrade`, статы — `StatBoostingUpgrade`.
- У приручённой крысы базовые урон и броня ненулевые, чтобы генетические множители урона и брони реально меняли итоговые значения в GUI и бою.
- Суточный голод хранится на сервере и синхронизируется в данные сущности: экран крысы показывает съеденный сыр за текущие сутки и личный запас без ручного обновления окна.

Подробный список — в [03-улучшения.md](03-улучшения.md).

## Приручение дикой крысы

1. Загнать в угол.
2. Бросать сыр на землю (~10–15 кормлений, `cheeseFeedings` / `wildTrust`).
3. Сущность заменяется или превращается в `TamedRat` (логика в `Rat` + предметы).

Альтернатива: ловушка `RatTrapBlock`, сеть `RatCaptureNet`.

## Инвентарь и интерфейс

- `RatContainer` — слоты улучшений, шлем, знамя, держимый предмет.
- Открытие: `OpenRatScreenPacket` (сервер → клиент).
- Посох радиуса / патруля / сыра — `ManageRatStaffPacket`, `SyncRatStaffPacket`.

## Варианты и косметика

- `RatVariantRegistry` — окраски, редкие варианты.
- Шляпы (отдельные модели в `client/model/hats/`).
- По конфигу: шапки Санты и праздничные в определённые даты.

## Связь с Citadel

`AbstractRat implements IAnimatedEntity` — анимации поедания, чесания, нюханья, танца через `Animation` из Citadel.

## Планируемые системы Rats Reborn

Краткая привязка к коду 8.1.3 и новым механикам (полный план — [11-план-разработки-rats-reborn.md](11-план-разработки-rats-reborn.md)).

| Система | Сейчас | План |

| Голод | нет | `hunger`, кормушка `rat_feeder`, расход при работе |
| Дом | `HOME_POS` (точка посоха) | Блок `rat_house` — см. [16-план-новых-механик](16-план-новых-механик.md) |

| Медик | нет | `rat_upgrade_medic`, лечение чумы в радиусе |
| Работа Create | нет | Сиденье + сундук + лента, улучшение `rat_upgrade_conveyor_worker` |

### Распорядок дня (черновик)

- День: рабочая точка (`PICKUP_POS`, `DEPOSIT_POS`, сиденье, карьер).
- Ночь: домик (`rat_house`), аналог улья у пчёл.
- Конфиг `nocturnalRats`: инверсия для ночной активности (ближе к реальной биологии крыс).
- Перед включением на кораблях Create Aeronautics — отдельный аудит навигации (этап 12 плана).
