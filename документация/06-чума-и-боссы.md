# Чума, боссы и враждебные крысы

## Система чумы

### Замысел автора (Modrinth)
«Больные крысы» — редкие дикие крысы с красными глазами и зелёной шерстью, **враждебны сразу**, переносят смертельную болезнь.

### Код

| Элемент | Реализация |
|---------|------------|
| Эффект | `PlagueMobEffect` → `RatsEffectRegistry.PLAGUE` (1.21.1: синхронизация в `onEffectAdded` / `onMobRemoved`, `Holder<MobEffect>`) |
| Дикая крыса с чумой | флаг `PLAGUE` у `Rat` |
| Синхронизация | `SyncPlaguePacket` (8.1.3 — улучшена) |
| Распространение | конфиг `plagueSpread` |
| Клиент | оверлей «чумных сердец» (`plagueHearts`, `singleRowPlagueOverlay`) |

Поведение: чумные крысы атакуют игроков; дикие защищают `PlagueDoctor`.

### Чумной доктор (`PlagueDoctor`)

- Спавн: `PlagueDoctorSpawner`, данные мира `PlagueDoctorWorldData`.
- GameRule: `doPlagueDoctorSpawning`.
- Категория: `CREATURE`.
- Связь с культом чумы и превращением в Чёрную смерть.

### Очищение

- `PurifyingLiquid` — сущность-жидкость против чумы; снятие эффекта через `removeEffect(Holder)`; конверсия зомби-жителя — `ZombieVillagerConversionHelper`.
- Предметы/зелья в линейке достижений `plague_cure`.

### Крысы-медики (план Rats Reborn)

Приручённая крыса с улучшением `rat_upgrade_medic`:

1. В радиусе (конфиг, ~16 блоков) ищет сущности из тега крыс с чумой (`PLAGUE` или эффект `PLAGUE`).
2. Подходит, проигрывает укол (шприц в лапах — визуал).
3. Снимает заражение; расход сыра или зелья из инвентаря/кормушки.
4. При отсутствии пути или расходника — запись в лог, без молчаливого пропуска тика.

См. этап 16 в [11-план-разработки-rats-reborn.md](11-план-разработки-rats-reborn.md).

## Чёрная смерть (`BlackDeath`)

| Параметр | Описание |
|----------|----------|
| Появление | Молния по чумному доктору (`blackDeathLightning`) |
| Тип | `BlackDeath` — MONSTER |
| Достижение | defeat_black_death |
| Спавн миньонов | облака `PlagueCloud`, звери `PlagueBeast` |
| Конфиг | лимиты спавна крыс/облаков/зверей, `bdConstantRatSpawns` |

Снаряды: `PlagueShot`.

## Король крыс (`RatKing`)

- Босс overworld.
- Механика: поглощение крыс (`reabsorb`), лечение (`heal rate`), постоянный спавн (`constant spawns`, `max rats`).
- Дикая крыса может начать превращение (`RAT_KING_TRANSFORMATION`).

## Свистун (`PiedPiper`)

| Свойство | Значение |
|----------|----------|
| Тип | Illager-подобный MONSTER |
| Рейд | добавлен в `Raid.RaiderType` как `RATS_PIPER` |
| Управление | крысы под музыкой дудки |
| GameRule | `doPiperSpawning` |
| Конфиг | `piperSpawnDecrease` |
| Дроп | музыкальные диски при убийстве крысой |

Блок `pied_garbage` — тематический мусор.

## Демоническая крыса (`DemonRat`)

- Нижний мир, враждебная.
- Дроп: сыр нижнего мира.
- Улучшение `rat_upgrade_demon`, вариант «душа» (1/100 вне soul sand valley в 8.1.3).
- Рецепт переключения: `DemonRatSwitchRecipe`.

## Боссы Ратлантис

Подробнее в [05-ratlantis.md](05-ratlantis.md). Конфигурация каждого босса — отдельная категория в `ServerConfig`:

- Automaton (дистанции боя, шанс выстрела)
- Neo-Ratlantean (порталы, молнии, блоки)
- Flying Dutchrat (радиус, меч)
- Rat Baron (высота полёта, частота стрельбы)
