# Конфигурация

Конфигурация Forge/NeoForge в двух файлах: **клиент** и **сервер**. После загрузки значения копируются в статические поля `RatConfig`.

## Цепочка загрузки

```
ConfigHolder.CLIENT_SPEC / SERVER_SPEC
    → ClientConfig / ServerConfig (поля @Config)
    → ModConfigEvent → RatConfig.bakeClient() / bakeServer()
```

## Сервер — категории

### Ратлантис
- `ratlantisEnabledByDefault` — **false** (набор данных выключен при создании мира).

### Появление
- `garbageSpawnRate`, `ratsSpawnLikeMonsters`, `ratSpawnDecrease`, `piperSpawnDecrease`.

### Деревни
- `villagePetShops`, веса обычных и зомби-деревень.
- `villageGarbageHeaps`, веса свалок.
- `golemsTargetRats` — големы атакуют крыс.

### Сыроделие
- `cheesemaking` — включить механику котла.
- `milkCauldronTime` — 150 тиков.
- `ratFluteDistance` — 2 блока.

### Чёрная смерть
- `blackDeathLightning`, `bdConstantRatSpawns`, лимиты крыс/облаков/зверей.

### Король крыс
- `ratKingReabsorb`, `ratKingHealRate`, `ratKingConstantSpawns`, `ratKingMaxRats`.

### Боссы Ратлантис
Отдельные секции: Automaton, Neo-Ratlantean, Dutchrat, Rat Baron — дистанции, шансы, урон, ограничение призыва только в измерении.

### Улучшения и RF
- `ratArmorMultiplier` — множитель брони от улучшения брони (8.1.3).
- `ratsChargeHeldItems` — зарядка предмета в лапах.
- `ratRFTransferBasic/Advanced/Elite/Extreme` — скорость передачи RF.
- `ratChargeBasic/...` — ёмкость.
- `upgradeRegenRate` — регенерация от remedy.
- Статы Warrior, God, Dragon, Demon, Voodoo, Ratinator, Nonbeliever — отдельные поля.
- `ratPsychicThrowsBlocks` — телекинез (константа false в bake).
- `carratDamagePerBite` — урон каррата за укус (8.1.3).

### Прочие настройки крыс
| Ключ | Значение по умолчанию |
|------|----------------------|
| `ratSackCapacity` | 16 |
| `maxRatRadius` | 16 |
| `pathfindHomeWorkDistance` | 128 |
| `pathfindFeederDistance` | 128 |
| `diurnalRats` | false |
| `defaultRatRadius` | 8 (константа) |
| `ratCageCramming` | 4 |
| `ratBreedingCooldown` | 24000 |
| `ratUpdateDelay` | 100 |
| `ratHarvestDelay` | 20 (константа) |

`pathfindHomeWorkDistance` задаёт предельное расстояние пути к рабочей базе и крысиным домикам. `pathfindFeederDistance` задаёт предельное расстояние поиска кормушки с сыром. Для старых конфигов значения этих двух полей ниже 128 в коде поднимаются до 128, чтобы дальние домики, работа и кормушки оставались доступными. Обычный `defaultRatRadius` оставлен 8, чтобы рабочие цели не сканировали огромные кубы и не подвешивали сервер. `diurnalRats` переносит сон приручённых крыс на ночь; по умолчанию крысы спят днём только с 4000 по 8000 тик.

## Где править для Rats Reborn

При порте на 1.21.1:

1. `ConfigHolder` / типы полей NeoForge config.
2. Значения по умолчанию в `ServerConfig` — баланс Rats Reborn можно вынести отдельно.
3. `RatConfig.bake*` — убедиться, что вызывается при перезагрузке конфига.

Файлы конфигурации в игре: `config/rats-client.toml`, `config/rats-server.toml` (точные имена — из `@Mod` id `rats`).
