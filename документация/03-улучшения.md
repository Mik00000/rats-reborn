# Улучшения крыс

Улучшения — главный способ специализации приручённой крысы. Реализованы как **предметы** в слотах инвентаря крысы.

## Архитектура

```
BaseRatUpgradeItem
├── StatBoostingRatUpgradeItem    — бонусы к здоровью, броне, урону
├── *RatUpgradeItem (конкретные)  — уникальная логика
└── CombinedRatUpgradeItem        — несколько улучшений в одном предмете
```

### Интерфейсы поведения (`server/items/upgrades/interfaces/`)

| Интерфейс | Назначение |
|----------|------------|
| `ChangesAIUpgrade` | Подмена целей ИИ, навигации, контроллера движения |
| `TickRatUpgrade` | Логика каждый тик |
| `StatBoostingUpgrade` | Модификаторы атрибутов |
| `ChangesTextureUpgrade` | Смена текстуры крысы |
| `ChangesOverlayUpgrade` | Оверлей поверх модели |
| `DamageImmunityUpgrade` | Иммунитет к типам урона |
| `HoldsItemUpgrade` | Отображение предмета в лапах |
| `GlowingEyesUpgrade` | Светящиеся глаза |
| `PostAttackUpgrade` | После атаки |
| `EquipmentListenerUpgrade` | Реакция на смену экипировки |
| `CombinedUpgrade` | Вложенные улучшения в комбинированном |

Утилита: `RatUpgradeUtils.hasUpgrade(TamedRat, Item)`.

## Планируемые улучшения Rats Reborn

Механики из дорожной карты [11-план-разработки-rats-reborn.md](11-план-разработки-rats-reborn.md) (этапы 13–19). В ванильной 8.1.3 этих улучшений **нет**.

| ID (черновик) | Интерфейсы | Назначение |
|---------------|------------|------------|
| `rat_upgrade_medic` | `ChangesAIUpgrade`, `HoldsItemUpgrade` | Поиск чумных крыс в радиусе, лечение шприцом |
| `rat_upgrade_conveyor_worker` | `ChangesAIUpgrade` | Работа на сиденье Create у ленты: предмет из сундука → обработка предмета на конвейере |
| `rat_upgrade_operator` | `ChangesAIUpgrade` | (уже в плане этапа 7) Рычаг, кнопка, ручка Create |

Связанные блоки (не улучшения): `rat_feeder` (кормушка), `rat_house` (домик), `rat_power_wheel` (колесо тяги). Голод и грабёж при голоде — системные, без отдельного улучшения.

### Конфликты (черновик)

| Улучшение | Несовместимо с |
|-----------|----------------|
| `rat_upgrade_conveyor_worker` | `rat_upgrade_crafting`, `rat_upgrade_operator` (одна «рабочая станция») |
| `rat_upgrade_medic` | — |
