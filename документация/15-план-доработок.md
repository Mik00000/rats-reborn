**Решение:** полностью убрать из Rats Reborn (ломают баланс и тики).

**Конкретно:**

1. Удалить регистрацию `RAT_UPGRADE_TICK_ACCELERATOR`, `RAT_UPGRADE_TIME_MANIPULATOR` из `RatsItemRegistry` (или пометить через `RatsRemovedContent` по образцу энергии).

5. Обновить документацию; при наличии предмета в мире — явный лог, без краша.

**Файлы:** `RatsItemRegistry.java`, `RatsCreativeTabRegistry.java`, `RatsUpgradeRecipes.java`, `server/items/upgrades/TickAccelRatUpgradeItem.java`, `TimeManipuRatorUpgradeItem.java`.

| Параметр | Примечание |

Combined-улучшения 35% — **оставить**.

### M2 — Потребление сыра и кормушка

**Связь:** [11-план этапы 13, 19](11-план-разработки-rats-reborn.md#этап-13-голод-крыс-и-кормушка-с-сыром); [04-игровые-системы](04-игровые-системы.md).

**Норма:** `round(4 × множитель_сыра)` кусков за 24 000 тиков; равномерность → % работы и regen:

| Съедено/сутки | Работа и regen |
|---------------|----------------|
| 4 | 100% |
| 3 | 75% |
| 2 | 50% |
| 1 | 25% |
| 0 | не работает; **M2-d** — воровство из контейнеров |

| Подзадача | Конкретно |
|-----------|-----------|
| **M2-a** | ✅ Поля `cheeseEatenToday`, `lastFeedDay`, множитель скорости целей; regen × тот же % |
| **M2-b** | ✅ Слот OFFHAND (`RatHelmetLayer`) → инвентарь сыра max **16**, фильтр `rats:cheese` / тег еды |
| **M2-c** | ✅ Блок `rat_cheese_feeder`: BE как бочка, только сыр; рецепт; `RatSeekCheeseGoal` — поиск личного запаса и кормушки |
| **M2-d** | ✅ При 0 сыра — голодный поиск сыра в контейнерах, уважать `unraidable_containers` |
| **M2-e** | **Create I-C2** — жёлоб/шлюз в кормушку (после M2-c) |

**Модель кормушки:** `feeder_model/Feeder.json` и `feeder_model/Feeder_empty.json` внесены в ресурсы как `rat_cheese_feeder` и `rat_cheese_feeder_empty`. Блок `rat_cheese_feeder` зарегистрирован с `BlockEntity`, меню 1×9 и item capability; принимает только сыр (`c:cheese` и творческий сыр). Состояние `has_cheese` переключает полную/пустую модель: элемент `cheese` виден только если в инвентаре есть сыр.

Крысиный работяга теперь проверяет `create:item_application`, `create:deploying` и полировку наждачной бумагой, а на ленте не уходит в долгую рабочую задержку при пустой попытке: он остаётся у отмеченного участка ремня и ждёт подходящий перевозимый предмет, как раздатчик удерживает предмет под собой до обработки.

**Уточнение 2026-05-28 по участкам ленты:** точка **«применить»** ограничена конкретным отмеченным блоком ремня. Крыса читает положение предмета на общей ленте Create и применяет рецепт только если предмет находится внутри этого блока, поэтому несколько крыс могут работать на разных блоках одной ленты без пересечения рецептов.

**Исправление 2026-05-28 по отрисовке ленты:** после применения предмета крыса больше не отправляет полное обновление блока ремня на клиент. Состояние инвентаря ленты помечается изменённым без принудительной пересборки рендера Create/Flywheel, чтобы не ломать отрисовку ремня при работе со шейдерами.

**Уточнение 2026-05-28 по последовательной сборке:** крысиный работяга поддерживает `create:sequenced_assembly` для шагов раздатчика. Механизм точности собирается как в Create: золотой лист превращается в незавершённый механизм, затем следующие крысы применяют малую шестерню, большую шестерню и железный самородок по текущему шагу рецепта. Замена предмета на ремне идёт через `TransportedResult` Create с сохранением положения на ленте, чтобы предметы не дёргались при синхронизации.

**Исправление 2026-05-28 по запасу сыра:** поиск кормушки для пополнения личного запаса больше не запускается при любом неполном запасе. Рабочая крыса уходит к кормушке только когда запас снизился до 2 сыров или меньше, а у кормушки по-прежнему добирает запас до 16, если сыр доступен.

**Smoke 2026-05-28:** конвейерная линия Create подтверждена в игре: корпуса, `sequenced_assembly` (механизм точности), работа по отмеченному блоку ремня, несколько крыс на одной ленте, сиденье и пополнение запаса без срыва рабочей цепочки.

Крыса, сидящая на Create Seat, может слезть за сыром из кормушки и после рабочей операции вернуться на домашнее сиденье.
