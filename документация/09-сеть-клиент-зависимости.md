# Сеть, клиент, зависимости

## Сетевой канал

Регистрация: `RatsNetworkHandler.registerPayloads(RegisterPayloadHandlersEvent)` на шине мода (NeoForge 1.21.1).

- Версия протокола регистратора: `"1"`
- Транспорт: `CustomPacketPayload` + `PacketDistributor`
- Всего play-пакетов: **20**
- Совместимость: `RatsNetworkHandler.CHANNEL.send` / `sendToServer` сохранены; цели `allTarget()`, `playerTarget()`, `trackingEntityTarget()`, `trackingEntityAndSelfTarget()`, `trackingChunkTarget()`

### Направление (1.21.1)

| Направление | Пакеты |
|-------------|--------|
| Клиент → сервер | `ClearRatRecipe`, `CycleRatRecipe`, `DismountRat`, `RatCommand`, `RatUpgradeVisibility`, `SetDancingRat`, `SetRatName`, `SyncArmSwing`, `SyncRatStaff`, `SyncRatTag`, `UpdateMobFilter` |
| Сервер → клиент | `ChangeRatlantisStatus`, `ManageRatStaff`, `OpenRatScreen`, `SyncPlague`, `SyncThrownBlock`, `UpdateCurdlerFluid`, `UpdateRatFluid`, `UpdateRatMusic`, `UpdateSelectedRat` |

Каждый пакет — `record`, реализует `CustomPacketPayload`, поля `TYPE` и `STREAM_CODEC`, обработчик через `IPayloadContext.enqueueWork`.

## Клиентская часть

### Подписчики

| Класс | Шина |
|-------|------|
| `ModClientEvents` | MOD, CLIENT — модели, шейдеры, свойства предметов |
| `ForgeClientEvents` | Forge — рендер, оверлеи |

### Рендер

- **77+** файлов в `client/render/` — сущности, блоки, слои.
- `RatsModelLayers` — регистрация слоёв (крыса, шляпы, боссы).
- `RatsRenderType` — кастомные блески (флаги, «специальные» красители).
- `RatsBEWLR` — рендер предметов блоков в руке.

### Интерфейс (`client/gui/`)

- Экран крысы (инвентарь, команды, улучшения, боковая плашка статов и имя).
- Фильтр мобов, списки предметов.
- Верстак крыс, комбайнер улучшений.

### Частицы

`client/particle/` — ~13 типов (сыр, чума, портал и т.д.).

## Примеси (`mixin/`)

| Файл | Цель | Эффект |
|------|------|--------|
| `PiglinAiMixin` | `PiglinAi.isWearingGold` | Золото, если на пассажире крыса с **Idol** |
| `WardenMixin` | `Warden.canTargetEntity` | Страж игнорирует крысу с **Sculked** |

Конфиг: [`rats.mixins.json`](../Rats-1.20/src/main/resources/rats.mixins.json), уровень **JAVA_21**, объявление в `META-INF/neoforge.mods.toml` (`[[mixins]]`). Refmap не генерируется (`-proc:none`); в dev включён `mixin.env.disableRefMap=true`.

## Зависимость Citadel

Обязательна. Используется для:

- `IAnimatedEntity` на крысах и боссах.
- Анимации `Animation` в `AbstractRat`, маунтах, боссах.
- Mixin citadel подключается в `build.gradle` (`-mixin.config=citadel.mixins.json`).

Без Citadel мод **не загрузится** (жёсткая зависимость в `mods.toml`).

## Локализация

| Файл | Язык |
|------|------|
| `en_us.json` (generated) | Английский, основной |
| `ru_ru.json` | Русский |
| `uk_ua`, `zh_cn`, `zh_tw`, `ja_jp`, `tr_tr`, `sv_se` | Другие |

Описания команд, улучшений, достижений — в lang-файлах (источник «задумки» для игрока).

## Access Transformer

`META-INF/accesstransformer.cfg` — расширение доступа к полям ванили (пулы структур, котлы и т.д.).

## Полезные команды разработки

```bash
# Клиент (из папки Rats-1.20)
gradlew runClient

# Сервер
gradlew runServer

# Генерация данных
gradlew runData
```

Требуется JDK 17. Секреты (ник, uuid) — `secrets.properties` (опционально).
