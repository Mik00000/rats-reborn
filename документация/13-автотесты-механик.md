# Автоматическая проверка механик Rats Reborn (1.21.1)

См. также [`12-статус-порта-1.21.1.md`](12-статус-порта-1.21.1.md).

## 1. Сборка и JAR

```powershell
$env:JAVA_HOME = "C:\Program Files\Zulu\zulu-21"
Set-Location "C:\Users\user\Desktop\Rats Reborn\Rats-1.20"
.\gradlew.bat build
(jar tf "build\libs\Rats Reborn-1.21.1-9.0.0-dev.jar" | Select-String "textures/item/").Count
```

## 2. GameTests (NeoForge)

```powershell
.\gradlew.bat gameTestServer
```

Рекомендуемые тесты: приручение, патруль, транспорт с пустым сундуком, автосыроварка, открытие GUI крысы.

## 3. Smoke в клиенте

`.\gradlew.bat runClient` — креатив (иконки труб, сыроварки), патруль, GUI крысы, сыроварка без краша.

## 4. Логи

Искать: `rats` + `Exception`, `Failed to encode`, `Unable to load model.*rats`.

## 5. Скрипт моделей

Проверка parent без `minecraft:` в `src/main/resources/assets/rats/models/item/*.json` — см. раздел в истории коммита 2026-05-23.
